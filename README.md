# Kathan Shah - Portfolio 🚀

Welcome to my portfolio repository! This is the source code for my personal website, where I showcase my journey.

🌐 Live Site: kathan-shah-portfolio-75af.vercel.app

## 🌟 Features

**Interactive Elements:**
- Premium **glassmorphism** design with frosted-glass effects, backdrop blurs, and deep shadows
- Dynamic hover animations and sleek card elevations across all sections
- Modular JavaScript data rendering for Experience and Projects
- Smooth scroll navigation and dynamic sticky header

**Responsive Layout:**
- Adapts seamlessly to all screen sizes utilizing CSS Grid and Flexbox
- Intelligent scroll padding for perfectly aligned section anchors
